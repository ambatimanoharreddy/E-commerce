# 📊 E-Commerce Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive **E-Commerce Sales Dashboard** built using **Power BI** with data sourced from an Excel dataset.
It provides insights into sales performance, profitability, customer segments, and shipping trends to support business decision-making.

## 🎯 Objectives
* Analyze total sales, profit, and quantity
* Identify top-performing countries and products
* Understand customer segments and buying behavior
* Evaluate shipping methods and their impact
* Track sales trends over time

## 🛠️ Tools & Data Source
* **Power BI** → Data visualization & dashboard creation
* **Excel Dataset** → Data storage and preprocessing

## 📂 Dataset Description
The dataset contains:
* Order details (sales, quantity, profit)
* Product information (category, product name)
* Customer segments (Consumer, Corporate, Home Office)
* Shipping modes (Standard, Second Class, First Class, Same Day)
* Geographic data (country, region, market)
